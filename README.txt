MUSIC KEYBOARD - PRAKTEK 12

Cara membuka:
1. Ekstrak ZIP ini.
2. Buka Android Studio.
3. Pilih File > Open.
4. Pilih folder MusicKeyboard (folder yang berisi settings.gradle.kts).
5. Tunggu Gradle Sync selesai.
6. Jalankan aplikasi pada emulator atau HP.

Catatan:
- Project menggunakan Kotlin, Android Gradle Plugin 8.7.3, Gradle 8.9,
  JDK 17, dan compileSdk 35.
- Saat pertama kali dibuka, Android Studio perlu internet untuk mengunduh
  Gradle, Android Gradle Plugin, AndroidX AppCompat, dan Android SDK jika
  belum tersedia.
- Aplikasi dikunci pada mode landscape.
- Tidak membutuhkan izin audio khusus.
